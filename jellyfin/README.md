
# Jellyfin Media Server

## Overview
Self-hosted media server running in Docker on Arch Linux.

## Technologies
- Docker
- Jellyfin
- Portainer
- Tailscale

## Setup Process
1. Installed Docker using pacman
2. Created Portainer container
3. Deployed Jellyfin container
4. Configured media directories
5. Enabled remote access with Tailscale

## What I Learned
- Docker container management
- Networking and ports
- Remote access using VPN (Tailscale)
